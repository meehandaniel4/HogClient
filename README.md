# Hog V1

Hog V1 is a Fabric 1.21.11 client-side utility, training, render, and HUD mod. AutoClicker defaults to vanilla attack-cooldown timing so held weapons strike at full charge instead of being spam-clicked.

Build with `./gradlew build`. The remapped mod jar is written to `build/libs/hog-v1-1.0.1.jar`.

Open the ClickGUI with Right Shift. Configuration is stored in `config/hogv1/`.
