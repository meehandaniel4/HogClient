# Hog V1

Hog V1 is a modern client-side utility, training, render, and HUD mod for Minecraft Java Edition. It is built for Fabric on Minecraft 1.21.11 and gives players a clean, configurable interface without replacing the feel of vanilla Minecraft.

The client includes a searchable ClickGUI, configurable native fonts, keybinds, profiles, draggable HUD widgets, a top-right active-module list, PvP training indicators, colored ESP, multi-mode Fullbright, movement tools, and resilient local configuration. Press **Right Shift** in-game to open the interface.

## Safety

Hog V1 behaves like a normal Fabric client mod. It does not contain hidden injection, packet spoofing, or anti-cheat bypass code. Configuration remains local in `config/hogv1/`.

The website source is maintained on `main`. Current client source is available on the [`client-source`](https://github.com/meehandaniel4/HogClient/tree/client-source) branch.
