# Hog V1

Hog V1 is a Fabric 1.21.11 client-side utility, training, render, and HUD mod. It includes configurable native UI fonts, searchable modules, a top-right active-module list, colored entity ESP, multi-mode Fullbright, and cooldown-aware combat timing.

Build with `./gradlew build`. The remapped mod jar is written to `build/libs/hog-v1-1.1.1.jar`.

Open the ClickGUI with Right Shift. Configuration is stored in `config/hogv1/`.
