# Bundled font licenses

Comfortaa, Arimo (used for the “Arial Compatible” option), JetBrains Mono, and Roboto are distributed under the SIL Open Font License 1.1. Their copyright and license metadata is retained in the font files. The common license text is included in `OFL.txt`.

Arial itself is a proprietary Microsoft typeface and is not redistributed by Hog V1. Arimo is metrically compatible with Arial and provides the closest redistributable option.
